# Emoji Logo Fit — мини-апп

Статический сайт (без бэкенда), который:

1. Принимает готовый Lottie-JSON (или `.tgs`) эмодзи.
2. Показывает превью анимации и дерево слоёв/групп с переключателем видимости
   (👁), чтобы вы могли, как в After Effects, скрывая элементы, найти нужную
   фигуру.
3. По клику на слой/группу выбирает её как "слот под лого".
4. Принимает ваш SVG-лого, вписывает его контуры на место старой фигуры
   (по размеру и центру), сохраняя исходный анимационный трансформ
   (позицию/поворот/масштаб слоя или группы не трогает).
5. Даёт настроить заливку и обводку (цвет + толщина).
6. Экспортирует результат как `.tgs` (gzip-сжатый Lottie-JSON) — обычным
   файлом, который вы вручную закидываете в @Stickers.

## Как выложить на GitHub Pages

1. Создайте новый репозиторий на GitHub, залейте в него все файлы из этой
   папки (`index.html`, `style.css`, `app.js`, `svgpath.js`,
   `lottie-tools.js`).
2. В репозитории: **Settings → Pages → Source** → выберите ветку `main` и
   папку `/root`. Сохраните.
3. Через минуту-две сайт будет доступен по адресу вида
   `https://<ваш_логин>.github.io/<репозиторий>/`.
4. Если у вас свой домен — подключите его через **Settings → Pages →
   Custom domain** (не забудьте настроить CNAME-запись у себя в DNS).

## Как подключить как Web App в BotFather

1. Напишите **@BotFather** → `/mybots` → выберите вашего бота.
2. **Bot Settings → Menu Button → Configure Menu Button**.
3. Пришлите ссылку на ваш сайт (GitHub Pages или свой домен) — она должна
   быть **https**, иначе Telegram её не примет.
4. Готово — в чате с ботом появится кнопка меню, которая открывает этот
   мини-апп.

(Если хотите отдельную inline-кнопку "Открыть редактор" вместо/вместе с
меню — это делается через `web_app` в `InlineKeyboardButton` на стороне
бота; я могу добавить такую кнопку в `bot.py`, если понадобится.)

## Важные ограничения текущей версии

- Из SVG используются только `<path>` (плюс базовая поддержка `<rect>` и
  `<circle>` как запасной вариант). Если лого сделано другими примитивами
  (`<polygon>`, `<ellipse>` и т.п.) — конвертируйте их в `<path>` заранее
  (большинство редакторов, включая Illustrator/Figma/Inkscape, делают это
  через "Object to Path" / "Flatten").
- Цвет и текстуры оригинального SVG игнорируются — берётся только
  геометрия контуров, а заливка/обводка задаются вручную в интерфейсе.
- Один слот = один цвет заливки + один цвет/толщина обводки на все контуры
  лого разом (без раздельной покраски частей лого).
- Если в шаблоне у выбранного слота изначально не было ни одной фигуры
  (пустая группа-заглушка), лого вписывается в дефолтный квадрат 100×100
  по центру группы.
